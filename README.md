# Cloud Pillow - Премиальный интернет-магазин подушек 🛏️

Современный, стильный и уютный интернет-магазин подушек с минималистичным премиальным дизайном.

## 🌟 Особенности

### Дизайн
- **Минималистичный премиальный стиль** с мягкими оттенками (молочный, бежевый, светло-серый, нежно-голубой)
- **Адаптивный дизайн** для всех устройств (мобильные, планшеты, десктопы)
- Округлые элементы, мягкие тени и эстетичные фотографии
- Атмосфера комфорта, чистоты и спокойствия

### Функциональность

#### 1. **Главный экран**
- Привлекательный заголовок и подзаголовок
- Призывные кнопки для начала покупок
- Эстетичное изображение подушки на кровати

#### 2. **Каталог товаров**
- 13 товаров в 6 категориях:
  - Ортопедические подушки
  - Подушки для сна на боку
  - Подушки для сна на спине
  - Мягкие пуховые подушки
  - Подушки для детей
  - Декоративные подушки

#### 3. **Система фильтрации**
- Фильтр по категории
- Фильтр по цене (с ползунком)
- Фильтр по размеру
- Фильтр по наполнителю
- Возможность сброса фильтров

#### 4. **Помощник выбора подушки**
- Интерактивный опросник с 3 вопросами:
  - Позиция сна (боку, спина, живот)
  - Предпочтение твёрдости
  - Наличие дискомфорта в шее
- Персональные рекомендации на основе ответов

#### 5. **Преимущества компании**
- Гипоаллергенные материалы
- Доставка по всему Казахстану
- 30 дней на возврат
- Гарантия качества
- Премиальный контроль

#### 6. **Отзывы покупателей**
- 3 реалистичных отзыва с рейтингом 5 звёзд
- Фотографии покупателей

#### 7. **Акция**
- Заметный блок со скидкой 20% на первую покупку
- Промокод WELCOME20
- Функция копирования промокода в буфер обмена

#### 8. **FAQ (Часто задаваемые вопросы)**
- Как выбрать правильную высоту подушки?
- Как ухаживать за подушкой?
- Можно ли вернуть подушку?
- Сколько занимает доставка?
- Какие материалы используются?
- Аккордеон с раскрывающимися ответами

#### 9. **Корзина**
- Боковая панель с товарами
- Изменение количества товаров
- Удаление товаров из корзины
- Подсчёт итоговой суммы
- Счётчик товаров в навигации
- Сохранение корзины в localStorage

#### 10. **Поиск товаров**
- Полнотекстовый поиск в реальном времени
- Поиск по названию и описанию

#### 11. **Контакты**

## ⚙️ Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/timati1231/cloud-pillow.git
cd cloud-pillow
```

2. Откройте `index.html` в браузере или используйте локальный сервер:
```bash
python -m http.server 8000
# или
npx http-server
```

3. Откройте `http://localhost:8000` в браузере
